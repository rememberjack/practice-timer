    Detection sensitivity

    Strict if talking or TV sets the timer off. Lenient if soft playing is missed.

    Keep counting through pauses

    A long soft note, a page turn or a short interruption keeps the clock running for this long. A longer quiet stops it.

    Keeps an audio recording of the session (microphone only) that you can save when you stop.

    Debug tools

    For trying things out on this device. Hold the Settings button for a moment to open this from anywhere.

    Sound source

    Demo sound feeds built-in test sounds to the detector (nothing is played aloud) and can run faster than real time to preview the rocket trip. Sessions played with it are saved to your practice log like any other.

    Replace my practice log with sample data

    Made-up sessions, to see the Home Screen and practice log after some use. Tap one twice to replace your practice log on this device with it. It then works like your own log: new sessions are added to it and the rocket carries on from it. Your own sessions are deleted, so save your practice log as a file first if you want to keep it.
